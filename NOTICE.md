# Notice

This repository holds **only original Rust code**, written from scratch for Horizon. It contains no
code, models, textures, sounds or other assets from the Forge/Fabric mod "The Man From The Fog" by
M_Productions, and it was not made by decompiling it. The behaviour follows the mod's public
description (its CurseForge page and FAQ); numbers such as timers and distances are this project's
own choices and can all be changed in the in-game page or in `the-man-from-the-fog/config.txt`.

His model is built from plain boxes drawn with vanilla block sprites, so nothing has to be shipped.
